### 5.1. Topology Architecture

1. **Sum Channel (XOR):** Computes the sum bit directly via wave phase cancellation of `SourceA` and `SourceB` at `Mixer_Sum`.
2. **Carry Channel (AND):** Computes the carry bit by mixing `SourceA` and `SourceB` with the reference wave channel `SourceBias_Carry` at `Mixer_Carry`.

```
                    [ SourceA ]           [ SourceB ]
                       /   \                 /   \
                      /     \               /     \
                     /       \             /       \
                    v         v           v         v
             [ Mixer_Sum ]             [ Mixer_Carry ]
               (XOR/Sum)                  (AND/Carry)
                                              ^
                                              |
                                     [ SourceBias_Carry ]
```

$$v = \sqrt{0.5 \cdot C \cdot c_{\text{press}}}$$

$$C = \frac{2}{c_{\text{press}} \cdot dt^2} = \frac{2}{2.0 \cdot 0.0064} = 156.25$$
We configured the engine's `conductance_max = 200.0` to prevent clamping. This yields a wave speed of exactly $12.5$ hops/s, so $v \cdot dt = 1.0$ (matching the CFL limit).

### 14.1. Core Physical Discoveries & Solutions

1. **Baseline Pressure Equilibrium**:
   * *Problem*: Initializing all nodes to a density of $10.0$ while tuning the mixer's semantic mass $M_m > 1.0$ (e.g. $M_m = 20.0$) creates a steep baseline pressure gradient because $p_i = c_{\text{press}} \ln(1 + \rho_i/M_i)$.    * *Solution*: We set the baseline density of all nodes to be strictly proportional to their semantic mass:
     $$\rho_i^{\text{baseline}} = 10.0 \cdot M_i$$
     This guarantees uniform baseline pressure ($p_i^{\text{baseline}} = c_{\text{press}} \ln(11) \approx 4.7958$) across the entire manifold, completely eliminating baseline pressure gradients and DC mass transport drift.

2. **Conductance Minimum Clamp**:
   * *Problem*: Even when dampening background edges to weight $0.0$ in the graph, the SOL engine enforces a minimum conductance limit:
     $$\text{conductance}_{\text{min}} = 0.1$$

3. **Three-Point Quadratic Calibration**:

   * *Solution*: We modeled the mixer's amplitude response $R(x)$ as a quadratic function of the total driven amplitude $x$:
     $$R(x) = C_2 x^2 + C_1 x + D$$
