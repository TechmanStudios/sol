# SOL Lens avatar demo package

This package builds a 1080p narrated demo from genuine captures of the public SOL Lens Render deployment.

## Presenter

- Character: `production/avatar.png`, copied unchanged from `dAvatar_transparent.png`
- Animation: nearest-neighbor pixel-art scaling with a subtle glow and speaking bob
- Voice: Microsoft David Desktop, male, rate `1`, with a slight upbeat pitch lift

## Outputs

- `SOL-Lens-Manifold-Replay-Demo.mp4` — final H.264/AAC video
- `SOL-Lens-Manifold-Replay-Demo.en.srt` — English captions
- `render-manifest.json` — duration and encoding summary

The video uses nine timed scenes: problem, SOL identity, examples, semantic court, visible failure, proof export, Manifold Replay introduction, deterministic dynamics, and close.
